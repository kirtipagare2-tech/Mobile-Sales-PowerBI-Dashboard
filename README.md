## Key Insights & Project Highlights
**Revenue Overview:**  Tracked 769M in Total Sales with 19K units sold across 4K unique transactions.
**Geographical Distribution:** Interactive map visual showcasing Total Sales by City to identify top-performing regions.
**Product Performance:** Breakdown of sales by mobile models (Apple, OnePlus, Samsung, Xiaomi) and total quantities.
**Customer Feedback:** Visualized Customer Ratings with percentage breakdowns to monitor satisfaction levels.
**Time-Series Analysis:** Trends tracked by Month and Day Name to pinpoint peak shopping periods and seasonal demands.
**Payment Preferences:** Segmented transactions by payment methods (Credit Card, Debit Card, Cash, UPI) using a clean donut chart.

## 🛠️ Tech Stack & Tools Used
# Business Intelligence: Microsoft Power BI Desktop 
# Data Connectivity: Excel Dataset
# Data Transformation: Power Query (ETL process, data cleaning, and data type formatting)
# Visualizations: Map Visual, Bar Charts, Line Charts, Donut Charts, and Card KPIs

## ⚙️ How to View the Project
1. Clone this repository to your local machine.
2. Ensure you have the latest version of Power BI Desktop installed.
3. Open the Mobile-Sales-PowerBI-Dashboard.pbix  file.
4. Note: If maps do not load, ensure that "Map and Filled Map visuals" is enabled in your Power BI Global Security Options.
